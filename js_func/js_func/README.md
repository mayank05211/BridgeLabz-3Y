# Assignment 5 - JavaScript Functions Submission

This folder contains 9 separate JavaScript files, one for each question.

## Run with Node.js
Open a terminal in this folder and run a file, for example:

`node Q1_Callback_Greeting.js`

You can run each of the other `.js` files the same way.

## Notes
- Q1-Q9 use core JavaScript (ES6+) only.
- Q2 uses a callback function with Array.map().
- Q3 demonstrates lexical `this` in arrow functions and fixes it with a normal function.
- Q5-Q6 demonstrate constructor-function prototype inheritance.
- Q7 demonstrates closures.
- Q8 adds a custom `myMap()` method to Array.prototype.
- Q9 demonstrates ES6 class inheritance with `extends` and `super()`.

No frameworks or external libraries are required.
