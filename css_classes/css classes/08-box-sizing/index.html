Box-Sizing Comparison

Compare the default content-box model with border-box.

content-box

Width: 220px
Padding: 20px
Border: 5px

Total width = 220 + 40 + 10 = 270px.

border-box

Width: 220px
Padding: 20px
Border: 5px

Total width stays 220px; padding and border fit inside the width.

Both examples use the same declared width, padding, and border.
