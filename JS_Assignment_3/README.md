# Assignment 3 — JavaScript

Each question is in a separate `.js` file. The files use strict mode where appropriate and include comments for logic and debugging.

## Run a file
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open a terminal in the folder.
4. Run, for example: `node Q1_Dynamic_Data_Parser.js`

Run each file separately. Q4 and Q8 include explanations of the original errors as comments, with corrected runnable versions. Q5's original order is explained in comments and the corrected code is runnable.
