CSS Responsive Design Assignment

This folder contains 10 independent projects. Each project has a descriptive HTML filename
and a matching CSS filename; no files are named q1/q2 and so on.

To run a project:
1. Open the matching .html file in a browser.
2. Keep its matching .css file in the same folder.
3. Resize the browser to test the responsive breakpoints.

All examples use HTML5 and CSS only. No JavaScript or external CSS frameworks are used.
Some gallery/profile images are loaded from Unsplash, so an internet connection is needed
to display those remote images.
