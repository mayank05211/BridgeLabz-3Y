Three Principles of Responsive Design

Core ideas that help websites adapt to every screen.

Fluid Layouts

Use flexible measurements so content can grow or shrink with the viewport.

width: min(100%, 1100px);

Flexible Media

Images and videos should fit within their containers without overflowing.

img { max-width: 100%; }

Breakpoints

Use media queries to adjust the layout at useful screen widths.

@media (max-width: 600px)

Responsive by design.
