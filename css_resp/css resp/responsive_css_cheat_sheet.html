Responsive CSS Cheat Sheet

Quick notes for building adaptable web pages.

Filters

Change the visual appearance of images.

filter: grayscale(1);

Media Queries

Apply styles when viewport conditions match.

@media (max-width: 700px) { ... }

Responsive Design

Make content work across different screen sizes.

width: min(100%, 1100px);

Typography

Scale text smoothly between size limits.

font-size: clamp(1rem, 2vw, 1.5rem);
