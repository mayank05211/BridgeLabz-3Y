ASSIGNMENT 10 — BOOTSTRAP 5

This folder contains 10 independent Bootstrap 5 projects.
Each project has a descriptive HTML filename and a matching CSS filename.
There are no q1.html or q1.css filenames.

How to run:
1. Extract this folder.
2. Open index.html to see the project list.
3. Open any descriptive .html file in your browser.
4. Keep its matching .css file in the same folder.

Bootstrap 5 CSS is loaded from the official jsDelivr CDN in every HTML file.
The Bootstrap JavaScript bundle is included only on the notifications dashboard
(dismissible alert) and travel showcase (carousel), where Bootstrap behavior needs it.
The custom blog also loads DM Sans from Google Fonts.

An internet connection is required for Bootstrap CDN assets, Google Fonts, and remote images.
The task tracker, pagination, buttons, and forms are visual demonstrations; no backend is connected.
