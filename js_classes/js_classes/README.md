# Assignment 4 - JS Classes Submission

This folder contains all 9 JavaScript solutions. Five questions use browser DOM forms and include matching HTML demo pages.

## Run the JavaScript-only questions with Node.js
From this folder, run:
- `node Q1_Ecommerce_Product_Manager.js`
- `node Q3_Library_Management_System.js ISBN002` (optional ISBN argument issues a book)
- `node Q6_Employee_Management_System.js`
- `node Q9_Shopping_Cart_Total.js`

## Run the form/DOM questions
For Q2, Q4, Q5, Q7, and Q8:
1. Keep each HTML file beside its matching `.js` file.
2. Open the HTML file in a browser (or use VS Code Live Server).
3. Fill in the form and submit it to test the validation or dynamic behavior.

All solutions use core JavaScript (ES6+) without frameworks or external libraries. Comments explain the main logic. Sample values can be changed inside each JS file.
