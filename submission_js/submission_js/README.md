# Assignment 1 - JavaScript Submission

This folder contains 10 separate JavaScript files, one for each assignment question.

## How to run
1. Open a terminal in this folder.
2. Run a file with Node.js, for example: `node Q1_Personalized_Login_Greeting.js`
3. For questions with sample inputs, edit the constants near the top of the file to test other values.

All programs use core JavaScript only. No frameworks or external libraries are required.
